# Travesty — brand guide

**Proposed display name:** Travesty
**Tagline:** *Statistically similar nonsense, since 1984.*

## Why this name

Kept — the Byte Magazine original's name, which is also exactly what the output is.

## The mark

Overlapping letter tiles: two legible, the third dissolving into a squiggle — an n-gram chain losing the plot.
